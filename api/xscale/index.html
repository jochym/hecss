    hecss.xscale¶

    Planned merge in 0.7

    plot_virial_stat also exists in hecss.monitor, where it plots the dimensional virial/T ratio and returns nothing. This module implements the sample-normalised variant and returns the amplitude correction matrix. The two will be merged into hecss.monitor.plot_virial_stat in 0.7; this function will remain as a compatibility alias for one release.

    This module provides a way to extract amplitude correction matrix from the eta calculation data generated by the estimate_width_scale method.

    plot_virial_stat(cryst, smpl, normal=True) ¶

    Plot normalised virial distributions and return an amplitude matrix.

    The virial |displacement * force| from width-estimation samples is divided by the sample mean, and 1/sqrt(virial) is plotted per element. normal=True fits a normal distribution; False fits chi-squared with 3 * natoms(element) degrees of freedom. The returned matrix has the shape of cryst.get_positions() and can be used as xscale_init.

    Note: hecss.monitor.plot_virial_stat shares this name but plots the dimensional virial/T ratio and returns nothing. The two implementations will be merged into the monitor function in 0.7; this one will stay as a compatibility alias for one release.

    def plot_virial_stat(cryst, smpl, normal=True):
    """Plot normalised virial distributions and return an amplitude matrix.

    The virial ``|displacement * force|`` from width-estimation samples is
    divided by the sample mean, and ``1/sqrt(virial)`` is plotted per element.
    ``normal=True`` fits a normal distribution; ``False`` fits chi-squared
    with ``3 * natoms(element)`` degrees of freedom. The returned matrix has
    the shape of ``cryst.get_positions()`` and can be used as ``xscale_init``.

    Note: ``hecss.monitor.plot_virial_stat`` shares this name but plots the
    dimensional virial/T ratio and returns nothing. The two implementations
    will be merged into the monitor function in 0.7; this one will stay as a
    compatibility alias for one release.
    """
    # shortcut: distinct algorithm under a colliding name; merge into hecss.monitor in 0.7.
    elems = cryst.get_chemical_symbols()
    elmap = cryst.get_atomic_numbers()
    vir = np.array([abs(s[2]*s[3]) for s in smpl])
    vir /= vir.mean(axis=(-1,-2))[:,None,None]
    nat = len(elems)
    xscale = np.ones(cryst.get_positions().shape)
    # m, s = plot_hist(vir.mean(axis=(-1,-2)), 'Total', 0, normal=True)
    mi = 1
    ma = 1
    for n, el in enumerate(sorted(set(elems))):
        elmask = np.array(elems)==el
        m, s = plot_hist(1/np.sqrt(vir[:, elmask, :].mean(axis=(-1,-2))), 
                         el, n+1, normal=normal, df=3*sum(elmask))
        if mi > m-3*s:
            mi = m-3*s
        if ma < m+3*s:
            ma = m+3*s
        xscale[elmask] = m
    plt.axvline(1, ls=':', color='C5', label='Equilibrium')
    plt.xlim(mi, ma)
    plt.legend()
    plt.title('Normalized Virial distribution in the sample')
    plt.ylabel('Probability density')
    plt.xlabel('Normalized Virial');
    return xscale
