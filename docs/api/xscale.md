# hecss.xscale

!!! note "Planned merge in 0.7"
    `plot_virial_stat` also exists in `hecss.monitor`, where it plots the
    dimensional virial/T ratio and returns nothing. This module implements
    the sample-normalised variant and returns the amplitude correction
    matrix. The two will be merged into `hecss.monitor.plot_virial_stat` in
    0.7; this function will remain as a compatibility alias for one release.

::: hecss.xscale
