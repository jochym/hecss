# hecss.monitor

!!! note "Planned merge in 0.7"
    `plot_virial_stat` also exists in `hecss.xscale` with a different
    algorithm: it normalises the virial by the sample mean and returns an
    amplitude correction matrix. Here it plots the dimensional virial/T
    ratio and returns nothing. The two will be merged into this function in
    0.7, with a switch selecting the normalised variant and a compatibility
    alias left in `hecss.xscale`.
